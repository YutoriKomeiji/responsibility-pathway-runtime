# Release history

This directory preserves release-candidate, pre-public audit, migration, and compatibility records that are useful as historical evidence but are not current product guidance.

Files here are `HISTORICAL` lifecycle surfaces. Statements such as “current version”, “published version”, “source preview”, pending gates, or next-release posture must be read as claims about the state at the time the record was produced. They do not override `product-status.json`, the current documentation indexes under `docs/en` and `docs/ja`, or current release readback.

Historical records are retained rather than rewritten to mimic a later release. Current-facing guidance should live in the active product documentation and be reconciled after each version transition.
